Come funziona

1. Apri il documento

Trascina un PDF, una scansione o un file Office. Tutto viene elaborato sul tuo computer – nessun caricamento, nessuna chiamata API.

2. Controlla gli oscuramenti

Doxudel propone le corrispondenze in base a pacchetti di regole deterministiche e alla NER locale. Accetta, rifiuta o modifica ogni voce nella vista di calibrazione.

3. Esporta il risultato bonificato

Ottieni un file piatto e oscurato senza livelli di testo recuperabili, oltre a un report di oscuramento per la tua DPIA.

Perché l'architettura conta

Il punto debole del traffico dati nel cloud

Il caricamento di file sensibili verso endpoint di terze parti crea rischi di conformità e di responsabilità. Non appena i dati lasciano il tuo computer, la tracciabilità si interrompe. Inoltre l'oscuramento nel cloud a consumo fa crescere i costi operativi in proporzione al volume.

Il carico hardware degli LLM locali

Gli LLM locali da 70B+ risolvono il problema della privacy, ma richiedono costose GPU enterprise. I modelli generativi soffrono inoltre di deriva semantica e sono quindi inaffidabili per le operazioni di conformità.

Il vantaggio di Doxudel

Doxudel combina modelli NER locali ottimizzati e leggeri (Named Entity Recognition) con validazioni deterministiche tramite checksum. Funziona interamente su hardware standard, senza chiamate API esterne, e restituisce risultati prevedibili basati su regole.

Bonifica raster irreversibile

Le aree sensibili nei documenti vengono convertite definitivamente in raster bonificati. Questo impedisce la riestrazione del testo da livelli PDF nascosti. L'oscuramento è visivamente distruttivo e sicuro e non lascia metadati residui.
